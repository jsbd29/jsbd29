  ## 🚀 &nbsp;Featured Projects

  <br>

  ### [TaskFlow](https://github.com/jsbd29/taskflow) — Job Application Tracker
  Track every job application, contact, and interview in one place — built to
  prove I can ship a complete product end-to-end in the stack Kansas City
  .NET shops actually run. JWT auth with rotating refresh tokens, BOLA-safe
  API (every query scoped by the authenticated user, never a client-supplied
  id), full Docker Compose stack.
  **46 tests** (integration tests run against a real Postgres via
  Testcontainers, not a mock) · React 18 · TypeScript · ASP.NET Core 8 ·
  PostgreSQL · Docker · CI

  <br>

  ### [KC Transit Live](https://github.com/jsbd29/kc-transit-live) — Real-Time Transit Dashboard
  Live vehicle tracking for Kansas City public transit — a background worker
  ingests a GTFS-Realtime protobuf feed every 15 seconds and broadcasts
  position updates over SignalR to every connected client simultaneously.
  Verified the multi-client fan-out with two concurrent SignalR connections
  actually receiving identical live updates, and the feed-health degradation
  path by killing the feed and watching it recover.
  **40 tests** · SignalR · ASP.NET Core 8 · React · protobuf-net ·
  PostgreSQL · Docker · CI

  <br>

  ### [FundApp-Capstone](https://github.com/jsbd29/fundapp-capstone) — Security Revision of a Team Capstone
  A 2026 solo security audit of my own 2023 team capstone, treated as a real
  PR review, not a rewrite from scratch. Found and fixed **5 real
  vulnerabilities**: SQL injection, plaintext password storage, a forgeable
  client-readable session cookie, broken object-level authorization, and a
  donation-total data-integrity bug — every one documented with before/after
  in [`SECURITY.md`](https://github.com/jsbd29/fundapp-capstone/blob/main/SECURITY.md).
  Rate limiting, CI-enforced dependency scanning, and a Testcontainers-backed
  test that caught a real unhandled-exception bug in the donation flow.
  Next.js 14 · TypeScript · ASP.NET Core 8 · PostgreSQL · CI
